# Trabalho em JAVA, criando um cofre


![Static Badge](https://img.shields.io/badge/status-finalizado-black?style=flat-square&label=status&labelColor=black&color=green)

Projeto universitário desenvolvido para aplicar conceitos de Programação Orientada a Objetos e estruturas de dados. O sistema simula um cofre digital capaz de gerenciar diferentes moedas, realizar saques, listar o saldo e converter o valor total acumulado para Real (BRL)
